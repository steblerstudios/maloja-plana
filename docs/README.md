# Maloja Plana Documentation Index

## Purpose

This documentation system exists to support:

- long-term maintainability
- calm product evolution
- architectural consistency
- ethical clarity
- offline-first resilience

The goal is not documentation volume.

The goal is shared understanding.

---

# Start hier: das UX-Playbook

[`UX_PLAYBOOK.md`](UX_PLAYBOOK.md) — das „Grundgesetz" von Maloja Plana. Bündelt
Produktphilosophie, Designprinzipien und die zentrale Idee (Maloja verwaltet

# Cross-Project Principles

All documentation should aim for:

- clarity over cleverness
- long-term maintainability
- explainability
- calm language
- low cognitive load
- human-centered thinking

Avoid:
- hype language
- manipulative framing
- unnecessary complexity
- artificial urgency

# Important Principle
