# Life Web / Spinnennetz Konzept

Das Leben besteht nicht aus isolierten Formularen.

Alle Bereiche hängen zusammen.

## Grundidee

Eine Veränderung in einem Lebensbereich beeinflusst viele andere Bereiche.

Die App soll diese Zusammenhänge sichtbar machen — ruhig, verständlich und ohne Überforderung.

Nicht als komplizierter Graph.
Sondern als unterstützendes Orientierungssystem.

## Beispiele

### Umzug
Ein Umzug beeinflusst:
- Gemeinde
- Kanton
- Steuern
- Krankenkasse
- Prämienverbilligung
- Mietvertrag
- Hausratversicherung
- Einwohneramt
- Aufenthaltsbewilligung
- Parkplatz
- Kinderbetreuung
- Schule

### Arbeitsverlust
Beeinflusst:
- Einkommen
- ALV
- BVG
- AHV
- Budget
- Schulden
- Krankenkasse
- Sozialhilfe
- Steuern

### Krankheit
Beeinflusst:
- Arbeitsfähigkeit
- Taggeld
- UVG
- Krankenkasse
- IV
- Medikamente
- Budget
- Notfallkontakte

### Todesfall
Beeinflusst:
- Vollmachten
- Versicherungen
- Mietvertrag
- Erbschaft
- Konten
- Dokumente
- Angehörige
- AHV
- BVG

## Ziel

Die App soll:
- Zusammenhänge erklären
- Risiken früh sichtbar machen
- Dokumente verbinden
- Fristen erkennen
- emotionale Überforderung reduzieren

## Wichtig

Nicht:
- aggressiv
- gamifiziert
- social media artig
- kompliziert

Sondern:
- ruhig
- vertrauenswürdig
- klar
- menschlich
- schweizerisch
- lokal
- privat

## Zukunft

Mögliche spätere Features:
- visuelle Lebenskarte
- Abhängigkeits-System
- Ereignis-basierte Hinweise
- Vorsorge-Netz
- Familien-Netz
- Haushaltsmodell
