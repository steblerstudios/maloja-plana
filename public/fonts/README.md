# Schriften — Lizenz & Herkunft

Alle hier mitgelieferten WOFF2-Schriften stehen unter der **SIL Open Font
License 1.1** (vollständiger Text + Copyright-Header: [`OFL.txt`](./OFL.txt)).
Sie werden lokal gehostet (keine externen Requests) — passend zur
Privacy-/Local-First-Architektur von Maloja Plana.

| Schrift | Einsatz in der App | Quelle |
|---------|--------------------|--------|
| **Lexend** | Body, Navigation, Formulare — auf Leseflüssigkeit getuned | https://github.com/googlefonts/lexend |
| **Hanken Grotesk** | Editoriale Headlines + Wortmarke | https://github.com/marcologous/hanken-grotesk |
| **Atkinson Hyperlegible** | Accessibility-Toggle (maximale Buchstaben-Eindeutigkeit) | https://www.brailleinstitute.org/freefont |

Begründung der Schriftwahl: siehe `docs/brand/brand-guidelines.md` §3.
