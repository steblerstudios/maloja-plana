# Human Approval Gates

## Goal

Define where human review is mandatory before data, decisions, or outputs become trusted.

## Approval Required For

- compliance-relevant outputs
- source mapping changes
- validation rule changes
- risk classification changes
- production release decisions
- external-facing claims
- deletion or retention policy changes

## Approval Not Required For

- draft notes
- local experiments
- formatting-only documentation edits
- non-production research notes
