# Never Export Data

## Principle

Some information should never leave the device automatically.

Exports must remain explicit, transparent and user-controlled.

## Never Auto-Export

- passwords
- recovery phrases
- private notes marked sensitive
- health details
- mental health notes
- violence or abuse documentation
- legal conflict evidence
- biometric identifiers
- authentication tokens
- encryption keys

## Require Explicit Consent

Before export, clearly explain:
- what is included
- where it will be saved
- whether encryption is active
- whether sensitive fields are included

## Default Export Philosophy

Prefer:
- minimal exports
- structured exports
- human-readable formats
- offline-first exports

Avoid:
- hidden cloud sync
- silent uploads
- telemetry packaging
- analytics bundling

## Sensitive Categories

Potentially sensitive domains:
- health
- finances
- migration status
- social welfare
- legal disputes
- family conflict
- debt
- addiction
- disability status

## Future Security Layers

Possible future protections:
- field-level encryption
- export redaction
- temporary export files
- secure local-only backups
- encrypted QR transfer
- passphrase-protected archives

## Calm Security

Security should feel:
- understandable
- visible
- trustworthy
- non-technical
- calm

The user should never feel lost or manipulated.
