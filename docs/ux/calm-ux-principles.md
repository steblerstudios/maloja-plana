# Calm UX Principles

## Core Philosophy

Maloja Plana should reduce psychological pressure, not increase it.

The interface must feel:
- calm
- understandable
- human
- non-judgmental
- trustworthy
- quiet
- stable

## Never Use

- streaks
- gamification
- urgency marketing
- addictive mechanics
- dark patterns
- manipulative notifications
- panic language
- flashing warnings
- engagement optimization
- shame-based wording

## Prefer

- simple language
- progressive disclosure
- large touch targets
- quiet visual hierarchy
- low cognitive load
- clear next steps
- forgiving forms
- human-readable explanations
- accessibility-first navigation
- soft reminders instead of pressure

## Notification Philosophy

Notifications should:
- help with important deadlines
- reduce forgotten obligations
- avoid anxiety
- remain minimal

Never:
- spam
- guilt users
- create artificial urgency

## Emotional Design Goals

The user should feel:
- safer
- more organized
- less overwhelmed
- less ashamed
- more capable
- calmer during difficult life situations

## Swiss Context

The product should feel:
- neutral
- respectful
- institutionally trustworthy
- multilingual
- culturally calm
- privacy-oriented

## Accessibility

Accessibility is not optional.

The app should support:
- keyboard navigation
- screen readers
- reduced motion
- low-tech devices
- older users
- stressed users
- cognitively overloaded users
