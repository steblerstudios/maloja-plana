# Agent Memory Policy

## Goal

Define what agents may remember, reuse, ignore, or discard.

## Principles

- No hidden memory
- No personal data reuse without explicit purpose
- Context must be scoped
- Sensitive data must expire or be reloaded from source
- Human approval required for durable memory
