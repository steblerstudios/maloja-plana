# Prämienverbilligung Schweiz

## Wichtig
Jeder Kanton hat andere Regeln.

## Unterschiede
- Einkommen
- Vermögen
- Haushaltsgrösse
- Kinder
- EL Bezug
- Sozialhilfe
- Quellensteuer
- Wochenaufenthalter
- Studenten
- Selbständige

## Zürich
- automatische Prüfung teilweise
- IPV abhängig von steuerbarem Einkommen
- Bezug über SVA Zürich

## Bern
- andere Einkommensgrenzen
- teilweise Antrag nötig

## App Ideen
- automatische Hinweise
- keine automatische Berechnung ohne Kanton
- Warnung bei fehlenden Daten
- dokument checklist
- Fristen erinnern

## Wichtig für Architektur
- kantonale engine nötig
- keine hardcoded schweizweite logik
- derived state statt duplicated state
