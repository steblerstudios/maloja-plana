# Maloja Plana — Platform Context

## Identity
Maloja Plana is NOT:
- an AI chatbot
- an autonomous agent platform
- a hype AI wrapper

Maloja Plana IS:
- a governance-native operational runtime platform
- deterministic
- human-governed
- local-first
- audit-oriented
- runtime-first

## Core Principles
- Human accountability remains central
- Governance before automation
- Determinism before intelligence
- Validation before execution
- Traceability before convenience
- Calm UX over aggressive automation
- AI is optional and secondary

## Hard Constraints
- No hidden autonomous execution
- No opaque AI decision-making
- No uncontrolled background actions
- No unnecessary dependencies
- No cloud-first assumptions
- No breaking persistence migrations

## Architecture Direction
- modular
- bounded
- auditable
- reproducible
- rollback-capable
- evidence-oriented

## Runtime Priorities
- approval gates
- provenance
- audit trails
- validation lifecycle
- change control
- deterministic execution
