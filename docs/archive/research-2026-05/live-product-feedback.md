# Live Product Feedback

## Date Reset Behavior

Observation:
When resetting a date field, the previously selected date still remains visually visible.

Risk:
Creates uncertainty whether the reset actually worked.

Desired behavior:
After reset:
- field becomes visually neutral
- placeholder returns
- no ghost state remains
- user feels safe that value is cleared

Source:
Silvan feedback during walkthrough.

---

## Dashboard Attention Balance

Observation:
Many dashboard elements currently compete for equal visual attention.

Risk:
Subtle cognitive overload.

Future ideas:
- stronger visual hierarchy
- calmer secondary cards
- more whitespace
- one primary focus area

## Empty States

Observation:
Technically correct but emotionally cold.

Future direction:
Use calm supportive language instead of system language.

- incomplete
- missing

- you can add this later
