Die Karten zeigen Durchschnitte je Kanton, nicht Ihre eigene Lage. Was davon für Sie gilt, zeigt die App Schritt für Schritt, mit Ihren Angaben, auf Ihrem Gerät.

Telefon, Tablet, Laptop

Maloja Plana holen — in einer Minute.

Maloja Plana lässt sich auf den Startbildschirm oder ins Dock legen. Danach öffnet es sich mit eigenem Symbol und in einem eigenen Fenster, wie eine App.

iPhone und iPad

  1. Maloja Plana in Safari öffnen.
  2. Unten auf das Teilen-Zeichen tippen — das Quadrat mit dem Pfeil nach oben.
  3. «Zum Home-Bildschirm» wählen.
  4. Oben rechts auf «Hinzufügen» tippen.

Auf dem iPhone sind die Angaben in Safari und auf dem Startbildschirm getrennt gespeichert. Öffnen Sie Maloja Plana darum von Anfang an über das Symbol.

Android

  1. Maloja Plana in Chrome öffnen.
  2. Oben rechts auf die drei Punkte tippen.
  3. «App installieren» wählen — je nach Version «Zum Startbildschirm hinzufügen».
  4. Bestätigen.

Laptop und Computer

  1. Maloja Plana in Chrome oder Edge öffnen.
  2. Rechts in der Adresszeile auf das Installieren-Zeichen klicken — ein kleiner Bildschirm mit einem Pfeil.
  3. Bestätigen. Maloja Plana liegt danach bei Ihren Programmen.

Mac mit Safari: im Menü «Ablage» auf «Zum Dock hinzufügen» (ab Safari 17). Firefox am Computer kann das nicht — dort bleibt ein Lesezeichen.

Ihre Angaben

Was Sie eingeben, bleibt bei Ihnen.

Die Rechnungen laufen in Ihrem Browser. Was Sie eingeben, wird nicht an einen Server geschickt.

  • Kein Konto

    Keine Anmeldung. Der Zugangscode der Beta wird nur auf Ihrem Gerät geprüft.

  • Nur auf diesem Gerät

    Im Speicher Ihres Browsers — nicht bei uns und nicht bei Dritten.

  • Kein Tracking

    Keine Werbung, keine Analyse-Dienste. Der Hoster speichert beim Abruf kurz technische Zugriffsdaten (Datenschutz).

  • Quelloffen

    Der Quellcode ist öffentlich einsehbar.

Häufige Fragen

Warum brauche ich einen Zugangscode?

Maloja Plana ist noch in einer geschlossenen Beta. Das Beispiel geht ohne Code — mit erfundenen Daten, es wird nichts gespeichert.

Einen Code bekommen Sie per E-Mail: schreiben Sie an info@malojaplana.ch.

Was passiert, wenn ich das Gerät wechsle?

Ihre Angaben liegen nur in dem Browser, in dem Sie sie eingegeben haben. Für einen Wechsel oder als Vorsorge können Sie eine Sicherung als Datei speichern und später wieder einlesen.

Ersetzt die App eine Beratung?

Nein. Die App gibt Orientierung. Massgebend ist immer die Auskunft oder Verfügung der zuständigen Stelle.

Die App ist eine Orientierungshilfe auf Basis öffentlicher Informationen — keine Rechts- oder Finanzberatung.
